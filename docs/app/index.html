nodata treated as 0 · rasters are the original ones · Help – usagePre-screening aid for land managers: it is not a hazard mapping and does not replace expert assessment.Online trial version. The calculation runs in your browser, so it is meant for trying the tool with not-too-heavy data (rasters up to a few million pixels); it is not designed for intensive or bulk use. To work regularly or on large data use the QGIS plugin (the best choice for a single user) or the local version. The vector (GeoPackage) is only available in the plugin and in the local version.

Statistics

Export map (image)

PNG with title, legend, north arrow and scale, as you see it now (basemap, hillshade, layers, buildings).

Export mapping

Raster (uint8 GeoTIFF on the original grid) or vector (GeoPackage) of the processed mapping, with the current parameters written in the metadata.
The GeoPackage has 4 layers (original, homogenised, map_with_codes, changes) with the same codes as the raster and the QGIS style embedded; export can take tens of seconds.
The button downloads the raster and its .qml style: save them in the same folder (same name) and QGIS shows single-class values, from yellow to red. The GeoTIFF has nodata = 0.
